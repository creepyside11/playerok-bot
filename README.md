# Playerok Bot

Telegram-бот на aiogram 3 для автоматизации Playerok.

## Возможности

- несколько Playerok-аккаунтов;
- добавление аккаунта по схеме: proxy → cookie или email + код;
- профиль и баланс;
- уведомления о новых сообщениях, заказах, смене статуса и ошибках;
- автоподтверждение продаж PAID/PENDING → SENT;
- автоответчик по ключевой фразе или *;
- автовыдача постоянного текста или одноразового склада;
- просмотр своих товаров;
- мастер создания и публикации товаров;
- шаблоны товаров: сохранение заполненных параметров, повторное создание черновика и удаление шаблонов;
- каталог выставления товара: категория → игра или поиск игры;
- просмотр Playerok-чатов, пагинация истории и ответы прямо из Telegram;
- Cardinal-подобная система Python-плагинов с переключателем и настройками;
- SQLite для состояния, правил, склада, настроек плагинов и дедупликации событий.

Playerok не предоставляет публично документированный API. Интеграция использует фактические GraphQL-операции сайта и неофициальный клиент PlayerokAPI. Изменения на стороне Playerok могут потребовать обновления.

## Переменные окружения

Обязательна только:

    BOT_TOKEN=123456789:telegram_bot_token

По умолчанию бот автоматически создаёт SQLite-файл:

    ./playerok.db

При необходимости путь можно изменить:

    DATABASE_URL=sqlite+aiosqlite:////absolute/path/playerok.db

или относительным путём:

    DATABASE_URL=sqlite+aiosqlite:///data/playerok.db

Дополнительно:

    POLL_INTERVAL=6
    LOG_LEVEL=INFO

Cookies, proxy и одноразовый склад шифруются перед сохранением в SQLite. Ключ выводится из BOT_TOKEN, поэтому после смены BOT_TOKEN сохранённые Playerok-сессии нужно подключить заново.

## Запуск

Python 3.11+:

    python -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    export BOT_TOKEN='...'
    python bot.py

Таблицы и файл playerok.db создаются автоматически.

## Docker

Dockerfile использует постоянную SQLite-базу /data/playerok.db. Для сохранения данных между перезапусками подключите volume:

    docker build -t playerok-bot .
    docker run --rm \
      -e BOT_TOKEN='...' \
      -v playerok-data:/data \
      playerok-bot

## Подключение Playerok

1. Откройте Аккаунты → Добавить аккаунт.
2. Укажите proxy в формате ip:port, user:pass@ip:port или ip:port:user:pass. Символ - означает без proxy.
3. Выберите Cookie или Почта + код.
4. Для cookie вставьте строку вида token=...; __ddg5_=....
5. Для email бот вызывает getEmailAuthCode, затем принимает код из письма и проверяет его через checkEmailAuthCode. Полученная сессия сохраняется как cookies.

Для защиты Playerok важно сохранять стабильный IP/proxy и User-Agent сессии.

## Автоматизация

Фоновый worker опрашивает последние исходящие сделки и личные чаты. При первом подключении текущие события становятся baseline и не запускают уведомления или автоматические действия задним числом. Новые события и действия имеют отдельные идемпотентные ключи в SQLite, поэтому рестарты не создают дублей, а временные ошибки автоматических действий допускают повтор.

Для SQLite включены foreign_keys, busy_timeout и WAL, чтобы фоновые записи были устойчивее при параллельных операциях.

Автовыдача привязывается к Item ID. Можно использовать * как правило по умолчанию. Для склада одна непустая строка = одна зашифрованная выдача. Если склад пуст, автоподтверждение соответствующего заказа не выполняется.

## Выставление товара

Мастер получает игру, категории, способы получения, поля и доступные приоритеты прямо через Playerok API. Атрибуты выбираются кнопками, а поля товара запрашиваются по одному с отметкой обязательных полей — JSON вручную вводить не нужно. После создания можно выбрать приоритет публикации или оставить товар черновиком.

## Использованные реализации Playerok API

- alleexxeeyy/PlayerokAPI — профиль, баланс, чаты, сделки, товары и публикация;
- leizov/Seal-Playerok-Bot — актуальная email OTP схема getEmailAuthCode/checkEmailAuthCode;
- exfador/playerok-api — примеры автоматизации.

Пакет `playerokapi` вендорится непосредственно в репозитории для гарантии надёжного деплоя без внешних зависимостей от git во время `pip install`.


## Плагины

Плагины лежат в папке `plugins/`. При запуске бот автоматически загружает все `.py` файлы, кроме файлов, начинающихся с `_`.

Каждый плагин объявляет метаданные:

    PLUGIN_META = {
        "id": "my_plugin",
        "name": "My Plugin",
        "version": "1.0.0",
        "author": "Author",
        "description": "Описание",
        "settings": {
            "enabled_feature": {
                "label": "Функция",
                "type": "bool",
                "default": True,
            },
            "text": {
                "label": "Текст",
                "type": "str",
                "default": "hello",
            },
            "limit": {
                "label": "Лимит",
                "type": "int",
                "default": 5,
            },
            "mode": {
                "label": "Режим",
                "type": "choice",
                "choices": ["one", "two"],
                "default": "one",
            },
        },
    }

Поддерживаются async-хуки:

    async def on_message(ctx, chat, message):
        ...

    async def on_deal(ctx, deal):
        ...

Через `ctx` доступны активный Playerok-аккаунт, Playerok client, Telegram bot, фабрика SQLite-сессий и настройки плагина. Удобные методы:

    await ctx.send_chat(chat_id, "Сообщение в Playerok")
    await ctx.notify("Уведомление владельцу в Telegram")

В Telegram откройте **🧩 Плагины** → **📤 Загрузить плагин** и отправьте Python-файл документом. Бот проверит расширение, загрузит модуль и покажет ошибку, если `PLUGIN_META` или код плагина некорректны. После этого выберите плагин: там есть отдельный переключатель включения и кнопка **⚙️ Настройки**. Состояние и настройки сохраняются отдельно для каждого подключённого Playerok-аккаунта.

Плагины выполняют Python-код с правами процесса бота, поэтому загружайте только доверенные файлы. В репозитории есть пример: `plugins/example_echo.py`.

### Каталог товаров

В **📦 Товары → ➕ Выставить товар** доступны два сценария:

- **Категория → игра** — бот собирает категории из каталога Playerok, после выбора показывает подходящие игры.
- **Поиск игры** — поиск через Playerok API по части названия, затем выбор категории.

После этого используется мастер полей, цены, описания, изображения и приоритета публикации.

### Чаты

Раздел **💬 Чаты** показывает личные диалоги и количество непрочитанных сообщений. Внутри чата можно:

- читать последние сообщения;
- листать более старую историю страницами;
- отвечать прямо из Telegram;
- обновлять чат.

Уведомление о новом сообщении также содержит кнопки **Открыть чат** и **Ответить**.
